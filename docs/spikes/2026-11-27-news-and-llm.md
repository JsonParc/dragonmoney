# Spike: 무료 과거 뉴스 확보 + 무료 LLM 티어 (Plan 1 Task 2)

- 날짜: 2026-11-26 (KST)
- 상태: 뉴스 = 부분 확인, LLM 티어 = **미확인** (API 키 미입력)

## 1. 과거 뉴스

### GDELT GKG 2.0 원본 파일 (15분 단위)
- 파일 1개(2024-03-01 12:00): 압축 5.6~6.4MB, 해제 17.4MB, 기사 1,391건, 도메인 378개
- 기업 언급(V2Organizations/Persons): nvidia 5, microsoft 19, tesla 3, apple 2, exxon 0, federal reserve 9 (15분 기준)
- 하루 96개 파일 → 압축 약 580MB/일 → 2015~2025 전체 약 **2.3TB**. 시간당 1개 표본도 약 550GB.
- **결론: 원본 GKG 전체 다운로드는 불가.** 사건 사례집용 거시 사건 확인에만 표본으로 제한적으로 사용 가능.

### GDELT 이벤트 테이블 (export)
- 15분 파일 압축 88KB → 하루 약 8.5MB → 11년 약 33GB. 지정학 사건(CAMEO 코드)과 출처 URL 포함.
- 거시 사건(전쟁·분쟁) 탐지용으로는 감당 가능한 크기. 기업 뉴스에는 부적합.

### GDELT DOC 2.0 API (전문 검색)
- `nvidia sourcelang:english`, 2024-08-05 하루 → **기사 227건, 도메인 166개**. 2년 전 데이터 검색 가능 확인.
- 기사마다 제목·URL·도메인·날짜·언어 제공 → **출처 교차검증(설계 §7.1a)에 그대로 사용 가능**.
- 요청 제한: "5초에 1회". 첫 요청 후 연속 요청에서 429가 나왔고, 90초 대기 + 60초 간격으로도 5분 이상 계속 429 → IP 단위 쿨다운이 있는 것으로 보임.
- 2020·2017·2015년 시점과 `timelinevolraw` 모드는 429 때문에 **미확인**.

### Finnhub company-news
- 키 미입력으로 미확인. (알려진 바로는 무료 티어 과거 범위가 약 1년 → 2024~2025 백테스트에는 부족할 가능성)

### Plan 2 결정
1. **종목 단위 과거 뉴스 = GDELT DOC API**, 단 *토론 대상(후보·보유) 종목과 날짜만* 조회. 2년 × 하루 약 10쿼리 ≈ 5,000쿼리.
   - 크롤러 요구사항: 요청 간 최소 10초, 429 시 지수 백오프(최대 15분), 결과를 DB에 저장해 중단 후 이어서 실행, 하루치 쿼리를 묶어 밤새 실행.
   - 예상 소요: 5,000 × 10~20초 ≈ 14~28시간 (PC에서 밤새 1~2회).
2. **사례집 거시 사건(2015~2023) = GDELT 이벤트 테이블 표본 + LLM이 작성한 주요 사건 목록**의 교차 확인. DOC API `timelinevol` 모드가 2015년까지 되는지 먼저 재확인(429 해제 후).
3. 2017년 이전 DOC API 범위가 없으면 2015~2016 사례집은 이벤트 테이블만 사용.

## 2. 무료 LLM 티어

`.env`에 Gemini·Groq 키가 없어 **실측하지 못함**. 아래는 실측 전 임시값이며, 키를 받으면 Task 8 네트워크 테스트에서 실측해 이 표를 갱신한다.

| 좌석 | 1순위 (무료) | 2순위 (무료) | 비고 |
|---|---|---|---|
| chart_trend | Gemini Flash 계열 | Groq Llama 70B급 | 이미지 입력: Gemini |
| chart_volume | Groq Llama 70B급 | Gemini Flash-Lite 계열 | |
| chart_candle | Gemini Flash 계열 | Groq Llama 4 (vision 지원 모델) | 이미지 입력 |
| news_news | Groq Llama 70B급 | Gemini Flash-Lite 계열 | |
| news_case | Gemini Flash 계열 | Groq Qwen 계열 | |
| news_macro | Groq Qwen 계열 | Gemini Flash-Lite 계열 | |
| referee | Gemini Flash 계열 | Groq Llama 70B급 | |
| reporter | Gemini Flash 계열 | Groq Llama 70B급 | 긴 출력 |

- 정확한 모델 ID는 하드코딩하지 않고 `pricing.py`/설정의 기본값으로 두며, 실측 후 갱신.
- 같은 팀 안에서 제공자를 섞도록 배치함 (설계 §7.5).

## 3. 백테스트 2년치 1회 예상 소요

- 토론 1회 ≈ 좌석 6 × (1 + 반박 평균 0.5) + 심판 1 ≈ 10호출
- 백테스트 하루 토론 최대 3건(신호 있는 날만), 반박 1회 → 504거래일 × 평균 2건 × 10 ≈ **10,000호출**
- 무료 한도 합계를 하루 3,000~5,000호출로 가정하면 **2~4일**. → Plan 2에서 첫 튜닝은 격주 표본으로 줄여 1일 이내로 돌리고, 전체 실행은 그 다음.
- 캐시 덕분에 두 번째 실행부터는 숫자 파라미터 튜닝에 LLM 호출이 필요 없음.
